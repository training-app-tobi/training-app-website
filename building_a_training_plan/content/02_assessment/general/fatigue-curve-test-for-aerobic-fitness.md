# Fatigue Curve Test for Aerobic Fitness

**Type:** Test · **Trains:** Endurance, Recovery

**TL;DR:** On a foot-on campus board, campus to failure for one maximal set, record the time and rest for the same time, then do 4–5 more sets at a 1:1 work:rest ratio; the time (and so the rest) goes down each set. Test at the start and end of a training cycle to see how aerobically fit you are and how well you recover between efforts.

## Testing aerobic fitness: fatigue curve
| Step | What to do |
|---|---|
| 1 | On a foot-on campus board, campus until failure for one set, aiming for a maximal time |
| 2 | Record the time and rest for that same time |
| 3 | Do 4–5 more sets at a 1:1 work:rest ratio; the time (and so the rest) goes down each set |
| When | Test at the start and end of a training cycle to see how aerobically fit you are and how well you recover between efforts |
