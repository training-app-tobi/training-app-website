# 4x4 Boulder Circuits

**Type:** Exercise/protocol · **Trains:** Power endurance, Endurance

**TL;DR:** Choose four boulder problems and climb them back-to-back with little to no rest between problems, then rest before repeating; repeat each four times. The intent is to develop aerobic power through high-end efforts with limited rest, using varied boulder movement to push sustained output. This builds significant pump and power endurance.

## Workout

| Element | Detail |
|---|---|
| Problems | Choose four boulder problems |
| One set | Climb the 4 boulder problems back-to-back with little to no rest between problems |
| Sets | Repeat each four times back-to-back with minimal rest between repetitions |
| Rest between sets | Rest before repeating |
| Intensity | The problems should feel manageable for a single attempt but become near-maximal by the fourth rep |
| Total workout time | 32 min |
