# Recruitment Pulls Before Climbing

**Type:** Exercise/protocol · **Trains:** Finger strength

**TL;DR:** Train the fingers before climbing with recruitment pulls: an excellent warm-up, and you pull at high intensity on fresh fingers, which is safer and more effective. Build to maximum effort over 5–8 seconds pulling only with the fingers, one pull per hand per set, warm-up sets then 5–8 working sets with about 3 minutes rest; the training is autoregulated, so it can be done every session.

## Before climbing: recruitment pulls
- Part of a minimalist strength routine (the note A Minimalist Strength Routine for Climbers): recruitment pulls before climbing, with shoulder exercises in their rests, then the climbing session, then supersets.
- Finger training is one of the only parts done before climbing: it is an excellent warm-up, and it lets you pull at high intensity instead of with fingers fatigued from climbing, which makes it safer and more effective.
- Execution: start pulling gently, build up to maximum effort over 5–8 seconds, then relax. Rather than pulling like a deadlift or from the shoulder, focus on pulling only with the fingers as much as possible. This takes getting used to, because the natural inclination is to yank with the arms, but isolating the fingers is much less taxing on other muscles and may give better finger engagement in certain positions.

| Recruitment pulls | Dose |
|---|---|
| One set | One pull on each hand |
| Warm-up sets | The first several sets, at your own pace |
| Working sets | Once the fingers feel awake: 5–8 sets |
| Rest between working sets | About 3 minutes |

- Frequency: this training is more autoregulated than traditional hangboarding, so you can do it every session. Any new addition needs care: if you're worried about overdoing it, start with once a week.
- A force gauge shows how hard you are actually pulling and lets you compare how strong your fingers are that day with previous days.
