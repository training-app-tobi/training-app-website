# Bouldering Session Order: Most Skill-Dependent First

**Type:** Session, Principles · **Trains:** Technique, Power, Finger strength · **For:** Boulderers

**TL;DR:** Bouldering is more skill dependent than route climbing, so the skill requirement of the exercises should decrease through the workout: warm-up, then technical and hard problems (your best attempts), then specific skill work, then strength sets, hangboard work or even campus board training.

## Session order: most skill-dependent first

Bouldering is more skill dependent than route climbing. The skill requirement of the exercises should decrease through the workout.

| Order | What to do |
|---|---|
| 1 | Warm-up |
| 2 | Technical and hard problems (your best attempts) |
| 3 | Specific skill work |
| 4 | Strength sets, hangboard work, even campus board training |
